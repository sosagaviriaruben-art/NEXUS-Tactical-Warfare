# Skill: Character Ability

## Procedimiento
1. **Diseño de Habilidad**:
   - Asignar tiempo de enfriamiento (cooldown) y costo energético.
   - Establecer telegrafiado audiovisual claro para aliados y rivales.
2. **Lógica de Ejecución**:
   - *Vulcan*: Instanciación de barrera de escudo 3D con puntos de vida propios.
   - *Nyx*: Pulso radial EMP con afectación temporal de sensores enemigos.
   - *Razor*: Pulso de escaneo de proximidad con refuerzo de escudo defensivo.
