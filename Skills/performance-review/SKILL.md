# Skill: Performance Review

## Procedimiento
1. **Medición de Tasa de Cuadros**:
   - Monitorizar frame time estable (meta 16.6 ms para 60 FPS).
2. **Optimización de Geometría**:
   - Culling de oclusión, límites en recuento de partículas activas y reutilización de buffers.
