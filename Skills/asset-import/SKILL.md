# Skill: Asset Import

## Procedimiento
1. **Verificación de Coherencia Visual**:
   - Asegurar paleta sci-fi militar (azul noche, cian, acentos ámbar, violeta alienígena, esmeralda legendario).
2. **Comprobación de Escala y Pivote**:
   - Escala estándar en metros (altura de operador ~1.8m).
